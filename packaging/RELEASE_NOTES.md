**New in 0.9.3 / Nouveautés de la 0.9.3 — security audit / audit de sécurité**

- **Sending always asks**: `github_write` was auto-approved because `api.github.com` is in the domain allow-list; allow-lists now only cover reads, and chained commands (`git log && curl …`, `$(…)`, `;`, `|`, new lines) always ask. / **Un envoi demande toujours** : `github_write` était accepté tout seul car `api.github.com` est dans la liste des domaines autorisés ; ces listes ne couvrent plus que les lectures, et les commandes enchaînées (`git log && curl …`, `$(…)`, `;`, `|`, retours à la ligne) demandent toujours.
- **Sandbox**: the low-level way to start programs (`_posixsubprocess.fork_exec`, also via reload) is blocked; `.env`, keys, `.git` and app data cannot be read by sandbox commands or Python scripts. / **Bac à sable** : le moyen bas niveau de lancer des programmes (`_posixsubprocess.fork_exec`, aussi par rechargement) est bloqué ; `.env`, clés, `.git` et données de l'application ne sont plus lisibles par les commandes ni les scripts Python.
- **Protected files** stay protected through `..`, symbolic links, capital letters and sub-folders; the search no longer reads them. / **Les fichiers protégés** le restent malgré `..`, les liens symboliques, les majuscules et les sous-dossiers ; la recherche ne les lit plus.
- **Web tools** refuse `localhost`, private networks and cloud metadata addresses, and check every redirect (`AGENT_ALLOW_PRIVATE_FETCH=1` to turn off). **Keys** (models, business APIs, GitHub, embeddings) never follow a redirect to another host. / **Les outils web** refusent `localhost`, les réseaux privés et les adresses de métadonnées du cloud, et vérifient chaque redirection (`AGENT_ALLOW_PRIVATE_FETCH=1` pour désactiver). **Les clés** (modèles, API métier, GitHub, embeddings) ne suivent jamais une redirection vers un autre site.
- **Prompt injection**: web, API and GitHub content reaches the model fenced as "data, not instructions". **Pages** cannot be framed by another site (clickjacking) and get a strict Content-Security-Policy. / **Injection de consignes** : le contenu web, API et GitHub arrive au modèle encadré comme « données, pas des instructions ». **Les pages** ne peuvent plus être intégrées par un autre site (clickjacking) et ont une Content-Security-Policy stricte.
- **Build**: GitHub Actions pinned to commit SHAs, pinned PyInstaller / pytest, build-provenance attestation (`gh attestation verify`). New `SECURITY.md`. No visible change in the interface. / **Construction** : GitHub Actions épinglées par SHA, PyInstaller / pytest épinglés, attestation de provenance (`gh attestation verify`). Nouveau `SECURITY.md`. Aucun changement visible dans l'interface.
